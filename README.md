# FoodFat

FoodFat 是料理熱量紀錄工具，可保存食材營養資料來源、建立可重複使用的食譜，並依本次製作份數計算與記錄熱量。

## 公開網站

- [GitHub Pages 公開版](https://yu810600-blip.github.io/FoodFat/)
- [完整資料庫版](https://foodfat-kitchen-journal.yu810600.chatgpt.site)

GitHub Pages 版將個人食材、食譜與烹飪紀錄保存在訪客自己的瀏覽器中。

## 主要功能

- 搜尋衛福部食藥署公開食品營養資料並自動帶入熱量
- 記錄品牌營養標示或其他公開資料來源
- 保存食譜、食材用量及每份熱量
- 記錄每次烹飪份數與整批熱量
- 紫金花卉介面與白貓吉祥物

## 本機開發

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

建立正式版本：

```bash
npm run build
```
